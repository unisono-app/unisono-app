# UnisOno Webアプリ — 背景と機能要件

## 1. 背景

### 団体概要

UnisOno は社会人によるクラシックギター合奏団体である。メンバー数は約50名。
定期的に練習を行い、年間を通じて演奏活動を行っている。

### 現状の情報共有手段と課題

現在、団体の情報共有は主に **LINE グループ** で行われている。
練習予定の連絡、出欠確認、年間スケジュールの共有など、運営に必要な情報がすべて LINE のチャット上でやり取りされており、以下のような課題が生じている。

- **情報が流れてしまう** — チャットの特性上、過去の連絡事項や決定事項が埋もれやすい
- **出欠管理が煩雑** — 練習ごとの出欠をチャット上で集計するのは運営メンバーの負担が大きい
- **スケジュールの一覧性が低い** — 練習予定や年間計画を俯瞰的に確認する手段がない

### アプリ開発の目的

これらの課題を解決するため、団体専用のWebアプリケーションを開発する。
練習予定・出欠・年間スケジュールなどの情報を一箇所に集約し、メンバーが必要な情報にいつでもアクセスできる状態を目指す。

---

## 2. 対象ユーザーとロール体系

### 対象ユーザー

UnisOno の団体メンバー全員（約50名）。
普段から LINE を利用しているため、認証には LINE Login を採用し、導入障壁を下げる。

### ロール体系

| ロール | 説明 |
|--------|------|
| provisional_member | 仮会員。新規登録後、管理者の承認を待つ状態 |
| member | メンバー。練習の閲覧・出欠回答・練習の作成・編集が可能 |
| admin | 管理者。member の権限に加え、ユーザー管理・承認が可能 |

## 3. 機能要件

### 3.1 認証・ユーザー管理

| 機能 | 概要 |
|------|------|
| LINE Login | LINE アカウントによるログイン（Supabase Auth 経由） |
| 新規登録 | LINE 認証後、プロフィール情報を入力して会員登録を申請 |
| 承認フロー | 管理者が新規登録を承認すると、一般メンバーとして利用可能になる |
| プロフィール編集 | 自身のニックネーム・パート・所属等を編集 |
| ユーザー管理 | 管理者がロール変更・承認を行う（admin のみ） |
| 名簿 | メンバー一覧の閲覧 |

### 3.2 練習管理

| 機能 | 概要 |
|------|------|
| 練習一覧 | 今後の練習予定を一覧表示 |
| 練習詳細 | 日時・場所・タイムスケジュール・練習内容などの詳細情報を表示 |
| 練習作成・編集 | メンバーが練習を作成・編集（member 以上） |

### 3.3 出欠管理

| 機能 | 概要 |
|------|------|
| 出欠回答 | 各練習に対して出席・未定・欠席を回答 |
| 出欠一覧 | 練習ごとの出欠状況を一覧表示 |

### 3.4 年間スケジュール

| 機能 | 概要 |
|------|------|
| PDF 閲覧 | Google Drive にアップロードされた年間スケジュールの PDF をアプリ上で閲覧 |

> **補足**: 年間スケジュールはフォーマットの自由度を優先し、アプリ内での編集機能は設けない。
> 運営メンバーが任意のツールで作成した PDF を Google Drive にアップロードし、アプリはそれを表示する。

### 3.5 楽曲管理

| 機能 | 概要 |
|------|------|
| 楽曲一覧 | 年度ごとの演奏楽曲を一覧表示 |
| 楽曲の追加・編集 | メンバーが楽曲情報を追加・編集（member 以上） |
| 練習との紐づけ | 各練習で取り組む楽曲を関連付けて表示 |

### 3.6 コメント

| 機能 | 概要 |
|------|------|
| 練習コメント | 練習に対してコメントを投稿（匿名投稿も可能） |
| 年間スケジュールコメント | 年間スケジュールに対してコメントを投稿（匿名投稿も可能） |

---

## 4. 非機能要件

| 項目 | 方針 |
|------|------|
| デバイス | スマートフォン利用を主軸とし、PC でも利用可能 |
| 認証方式 | LINE Login（メンバーが普段使い慣れた手段を利用） |
| コスト | 無料枠の範囲で運用（Vercel Hobby + Supabase Free） |
| 技術スタック | Next.js (App Router) + Supabase (PostgreSQL) + Vercel |
| コード管理 | GitHub |
